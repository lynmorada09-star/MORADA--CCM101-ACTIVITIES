# Mission Reflection

Completing Mission 3 helped me understand AWS, Microsoft Azure, and Google Cloud Platform better. **The cloud platform that impressed me the most was Microsoft Azure** because of its strong connection with Microsoft technologies. I learned that Azure is useful for organizations that already use Windows Server, Microsoft 365, and Active Directory.

**AWS, Azure, and GCP have many similarities.** All three provide cloud services such as virtual machines, storage, databases, networking, identity management, security, and other computing services. They also have global infrastructure that allows users to run applications and services in different locations.

**Business requirements are important when selecting a cloud platform.** The choice depends on factors such as budget, existing technology, performance, scalability, security, and the type of application. For example, Azure can be a good choice for a university using Microsoft products, while Google Cloud can be suitable for an AI research company. AWS can also be useful for startups and businesses that need scalable cloud services.

**Acting as a Cloud Solutions Consultant taught me** that there is no single cloud platform that is best for everyone. I need to understand the client's needs first and then choose the platform and services that can meet those requirements.

**My GitHub Cloud Computing Portfolio also improved after completing this mission.** I learned how to organize my files and technical information using Markdown. I also added documentation, comparison tables, recommendations, and screenshots from my KillerCoda activity. In KillerCoda, I was able to see the details of a Linux environment, including Ubuntu 24.04.4 LTS, CPU information, approximately 1.9 GiB of memory, and 19G of disk space. This helped me understand that cloud virtual machines also have resources such as an operating system, CPU, memory, and storage.

Overall, Mission 3 improved my knowledge of cloud platforms, Linux environments, and cloud service selection. It also helped me become more confident in documenting and explaining technical information.
