# Mission Reflection

Completing Mission 3 helped me understand more about AWS, Microsoft Azure, and Google Cloud Platform. I learned that these three cloud platforms offer similar services, but they also have different strengths. For me, Microsoft Azure was the most interesting because it works well with Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory.

I also learned that choosing a cloud platform depends on the needs of a business or organization. AWS can be a good choice for startups and businesses that need many cloud services and scalability. Azure is useful for organizations that already use Microsoft products, while Google Cloud is a good option for companies that focus on artificial intelligence, machine learning, data, and Kubernetes.

One of the activities I found interesting was using KillerCoda. I was able to check the details of a Linux environment using commands. I saw that the system was running Ubuntu 24.04.4 LTS. I also checked the CPU information, which showed an Intel Xeon processor, the available memory of about 1.9 GiB, and the disk space of 19G with about 30% being used. This helped me understand that a cloud virtual machine also has resources such as CPU, memory, storage, and an operating system.

Overall, this mission taught me that cloud computing is not only about learning different cloud providers. It is also about understanding the resources of a computer, comparing cloud services, and choosing the right platform based on a user's needs. This activity improved my knowledge of cloud computing and gave me more confidence in working with Linux and cloud technologies.
