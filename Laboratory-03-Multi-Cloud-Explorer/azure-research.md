# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's public cloud computing platform. It provides services for computing, storage, databases, networking, security, artificial intelligence, analytics, application development, and enterprise workloads.

## Global Infrastructure

Azure provides a worldwide infrastructure organized into geographies, regions, and availability-related infrastructure. Azure regions allow organizations to choose locations based on requirements such as performance, data residency, compliance, and availability. Microsoft provides an interactive Azure global infrastructure map showing regions and related information.

## Cloud Management Console

The Azure portal is a web-based unified console used to create, manage, and monitor Azure resources. Users can manage subscriptions, create resources, configure services, and monitor cloud deployments through the graphical interface.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtualized computing resources for running operating systems and applications in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage provides object storage for large amounts of unstructured data such as files, images, videos, backups, and application data.

### 3. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and services.

### 4. Azure SQL Database

Azure SQL Database is a managed relational database service based on Microsoft SQL technologies.

## Three Advantages

1. **Microsoft integration** – Azure integrates strongly with Microsoft technologies and enterprise environments.
2. **Global infrastructure** – Azure provides cloud infrastructure in many geographic regions.
3. **Enterprise capabilities** – Azure provides services for enterprise applications, security, governance, and hybrid environments.

## Typical Enterprise Use Cases

Azure can be used for Windows-based applications, enterprise applications, Microsoft SQL workloads, hybrid cloud environments, identity management, virtual desktops, data analytics, and artificial intelligence.
