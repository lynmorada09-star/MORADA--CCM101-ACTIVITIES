# Mission Reflection
 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important cloud infrastructure components because they provide the processing power needed to run applications and services. During the laboratory, I observed that the KillerCoda environment had an Intel Xeon E312xx processor, 1 CPU core, and 1.9 GiB of RAM. These resources allowed me to execute Linux commands and investigate the server environment.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable operating system environment for running applications, services, and cloud workloads. In this laboratory, I used Ubuntu in KillerCoda and Linux commands such as `lscpu`, `free -h`, `lsblk`, `df -h`, `findmnt`, and `ip addr` to investigate the server's resources.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps organize information about infrastructure before deployment. It makes it easier to understand the required resources, identify possible problems, and communicate the design to other people working on the project.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using terminal commands and identify its operating system, kernel, CPU, memory, storage, file systems, hostname, and IP address. I also learned how to identify cloud infrastructure components, compare AWS, Azure, and Google Cloud services, create a simple cloud architecture diagram, and document my work using Markdown and GitHub.
